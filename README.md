# Шифры

Статический учебный сайт без сборки и зависимостей. Восемь способов: Цезарь, Атбаш, скитала, Морзе со звуком, квадрат Полибия, сеть Фейстеля (DES), цифровой шифр, Виженер.

- index.html — структура страницы.
- styles.css — оформление и адаптивность.
- cipher.js — независимый модуль преобразования текста (CaesarCipher).
- app.js — интерфейс, состояние и анимация.

Откройте index.html в браузере. Файлы JavaScript загружаются с defer в порядке зависимостей. Для публикации на GitHub Pages используется ветка main, корневая папка.

Атбаш реализован в atbash.js: зеркальная замена букв, одинаковая для шифрования и расшифровки. Интерфейс показывает пары букв в одной плитке. Кириллица содержит 33 буквы, включая Ё; латиница — 26. Регистр и остальные символы сохраняются.

Новые модули:
- cipher-tools.js — общий формат таблиц и шагов.
- lesson-ciphers.js — демонстрации Цезаря и Атбаша.
- scytale.js — шифрование: запись по столбцам, чтение по строкам; расшифрование в обратном порядке, без дополнения.
- morse.js и morse-audio.js — кодирование и декодирование, визуальные сигналы, Web Audio 600 Гц. Длительности 1/3/7 по ITU-R M.1677-1; звук запускается нажатием кнопки и останавливается при смене режима или скрытии страницы.
- polybius.js — перестановка координат (столбец, строка); МАМА → ББВВ; три свободные клетки обозначены 1, 2, 3 для обратимости.
- feistel.js — DES по историческому FIPS 46-3, 16 раундов. HEX без дополнения; UTF-8 с PKCS#7 в независимых блоках. Контрольный пример: 0123456789ABCDEF, ключ 133457799BBCDFF1 → 85E813540F0AB405.
- digital.js — позиция + раздел; АНАНАС → 11 24 11 24 11 25. Алфавит без Ё.
- vigenere.js — таблица, дополнительный сдвиг +1, русский алфавит без Ё. АФРИКА + МАМА → НХЭЙЧБ.

Полибий, цифровой шифр и Морзе выдают заглавные буквы. Пробелы в цифровом шифре и Морзе разделяются знаком /; при кодировании последовательности пробелов нормализуются. Скитала сохраняет все символы и пробелы. Ключ Виженера продвигается только на буквах. Для Морзе язык выбирается явно, так как одинаковые сигналы могут обозначать латинские и русские буквы.

Источники:
- https://www.itu.int/rec/R-REC-M.1677/en
- https://csrc.nist.gov/pubs/fips/46-3/final

Морзе: вкладка открывается с ручным ключом. Нажмите мышью или пальцем и удерживайте; также работает пробел на выбранной кнопке. Менее 0,36 с — точка, от 0,36 с — тире; пауза 0,54 с завершает букву, 1,26 с разделяет слова. Режим «Текст → Морзе» сохраняет преобразование текста и звуковое воспроизведение.
